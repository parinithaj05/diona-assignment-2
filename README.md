# Criminal Risk Assessment Request - ODK XLSForm

This repository contains the ODK XLSForm developed for the Criminal Risk Assessment Request form provided as part of the Odiona Technologies internship selection assignment.

## Files

- `Criminal_Risk_Assessment_Request.xlsx` - Completed ODK XLSForm
- `README.md` - Project documentation

## Form Features

- Personal information fields
- Gender selection
- Multiple identification selection
- Minimum two-identification validation
- Conditional display for Other ID details
- Conditional display for Manitoba Driver's Licence number
- Automatic display of the person's name on the agency section
- Risk assessment reason selection
- Consent-related conditional information
- Email validation
- Date validation
- Required field validation

## Testing

The XLSForm was tested using the ODK XLSForm Online / Enketo preview.

The following functionality was verified:

- Form loads successfully
- Conditional fields work correctly
- Identification validation works correctly
- Email validation works correctly
- Future dates are restricted
- Required fields are validated
- Calculated name is displayed correctly
